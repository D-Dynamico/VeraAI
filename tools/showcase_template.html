Vera writes WhatsApp messages to shop owners, and can't make up a number

A messaging bot for Indian local businesses: dentists, salons, restaurants, gyms and chemists. Python decides what is true and worth saying; an LLM only polishes the wording. Every number in a message has to trace back to the shop's own data, or the message doesn't go out.

Built by Dayanand for the magicpin AI Challenge · Source on GitHub

Every message, with a receipt for every number

Pick a case. The highlighted numbers in the message are each matched to the exact field they came from. Click a number to find its source.

    It notices what changed

    The server keeps the previous version of every context it receives. When a newer snapshot of a shop arrives, the next message names the change instead of repeating itself.

    It knows when to stop talking

    Replies go through a small state machine, not an LLM. Each thread below is the real output for that reply, along with the reason the bot gives.

    Sometimes the right message is none

    When the data doesn't support a message, or the customer hasn't agreed to that kind of contact, Vera sends nothing instead of inventing a reason to write.

      How a message is made

      The usual approach is reversed: code decides what to say, and the model only decides how it reads.

      1. factpack.pyPulls facts out of the shop's data, each tagged with the field it came from.
      2. cohort.pyCompares the shop with every peer in the dataset, so "other clinics get 23 calls" is computed, not guessed.
      3. templates.pyWrites a plain-English draft: the key fact first, one line of context, one simple ask.
      4. compose.pyGemini rephrases the approved lines within an 8-second budget. If it's slow or wrong, the draft ships.
      5. validate.pyBlocks unknown numbers, links, jargon, banned words, repeat messages and second asks.
      All shops, customers and figures are synthetic data from the challenge dataset. Messages on this page are the deterministic draft path, generated by tools/showcase.py with no LLM, so anyone can reproduce them exactly.
